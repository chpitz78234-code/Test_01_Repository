# Test_01_Repository

- [`motion-spec/STIL_UND_ANIMATIONSVORGABE.md`](motion-spec/STIL_UND_ANIMATIONSVORGABE.md): Stil- und Animationsvorgabe für automatisierten Schnitt und Motion Graphics

- [`motion-spec/tools/analyze_motion.py`](motion-spec/tools/analyze_motion.py): vermisst Videos (Schnitte, Shotlängen, Bildraten-Muster, Beat-Abweichung)
- [`stelen-visualisierung/index.html`](stelen-visualisierung/index.html): maßstabsgetreue Frontalansicht von vier weißen Stelen neben einem 1,80 m großen Menschen (SVG in cm-Einheiten, Maße in `CONFIG` änderbar); Vorschau: [`vorschau.png`](stelen-visualisierung/vorschau.png)
